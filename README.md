
# CGPA to Percentage Calculator

This web-based application allows students to calculate their CGPA (Cumulative Grade Point Average) and convert it into percentage for each semester. It also calculates the aggregate CGPA and the overall percentage.

## Features

* **Enter Student Details**: Input student name, roll number, and college name.
* **Enter CGPA for Each Semester**: Enter the CGPA values for each semester.
* **Calculate Percentage**: Based on the entered CGPA values, the percentage for each semester is calculated.
* **Aggregate CGPA and Percentage**: The aggregate CGPA and overall percentage are displayed.
* **Clear All**: Reset all inputs and results to start fresh.

### CGPA to Percentage Formula

* **If CGPA < 7**: Percentage = `7.1 * CGPA + 12`
* **If CGPA >= 7**: Percentage = `7.4 * CGPA + 12`

## How to Use

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/your-username/cgpa-to-percentage-calculator.git
   ```

2. Open the `index.html` file in your preferred browser.

3. **Enter Student Details**:

   * Name
   * Roll Number
   * College Name
   * Number of Semesters

4. **Enter CGPA**: Input the CGPA for each semester.

5. **Click on "Calculate"** to view the semester-wise CGPA, percentage, aggregate CGPA, and overall percentage.

6. **Click on "Clear All"** to reset all fields and results.
